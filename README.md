# Savepoint assets

Public images for the Savepoint game servers. Generated by `branding/logo.py` in the server repo; don't edit by hand.

| File | Use |
|---|---|
| `savepoint-32.png` | Unturned server-list thumbnail (`Config.txt` `Thumbnail`) |
| `savepoint-64.png` | Unturned lobby icon (`Config.txt` `Icon`) |

Served through jsDelivr at a fixed tag, e.g. `https://cdn.jsdelivr.net/gh/Corbyncc/savepoint-assets@v1/savepoint-32.png`.
A new version is a new tag (`v2`), then the URLs in the server config.
